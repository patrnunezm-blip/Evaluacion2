# Evaluacion 2 - Sistema de Geolocalización
Desarrollado por: Bastian Toloza y Patricio Núñez.

## Descripción del Proyecto
Este proyecto contiene una mejora al prototipo de software de geolocalización para los visitantes de la Biblioteca Nacional, consumiendo la API de Graphhopper.

## Instrucciones de ejecución
1. Asegúrese de tener Python y la librería `requests` instalada.
2. Ejecute el script en la terminal con el comando: `python3 geolocalizacion.py`
3. Ingrese la ciudad de origen y de destino cuando el programa lo solicite.
4. Las instrucciones se mostrarán en español. 
5. Para salir del programa, ingrese 's' o 'salir' en cualquiera de las solicitudes.
